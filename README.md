### 1.Project Name 
 - FitLog — Workout Library & Fitness Planner
 

-----------

### 2.Short Description
-FitLog is a gym-focused app built with Next.js. It offers features such as browsing workout lists, viewing detailed exercise instructions, creating daily workout plans, and saving exercises for future use—all powered by a live REST API.

----------

### 3. Technologies Used
- Next.js
- TypeScript
- Tailwind CSS v4
- daisyui
- React Toastify
- REST API

------------------
### 4. Five (5) Key Features
- Workout Library — Browse a grid of 12+ workouts with muscle   group tags, equipment, duration, calories, and ratings.

- Detailed Workout Pages — Each workout has a dedicated details page with step-by-step instructions, stats table, and images.

- Daily Plan Builder — Add workouts to "Today's Plan," track total exercises, minutes, and calories in a live stats bar.

-  Save for Later — Bookmark workouts to a separate "Saved" list, with sorting by duration, calories, or rating.

-  Persistent Header Counters — Real-time "Plan" and "Saved" badge counts synced globally via React Context, visible from any page.
